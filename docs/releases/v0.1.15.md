# Video Download Companion 0.1.15

First public source and Windows installer candidate. This build is published as
a pre-release until clean-machine installation and uninstall verification is
complete.

## Quick install

1. Download `Video-Download-Companion-Setup-0.1.15.exe`,
   `video-download-companion-extension-0.6.0.zip` and `SHA256SUMS.txt`.
2. Verify the installer's SHA-256 against `SHA256SUMS.txt`, then run it.
3. Choose a media directory and leave the dependency PowerShell window open.
4. On first install, complete DouK's language and disclaimer screen yourself.
5. Extract the extension ZIP, open `chrome://extensions/`, enable Developer mode
   and load the extracted directory containing `manifest.json`.
6. Read `server.auth_token` from
   `%LOCALAPPDATA%\YouTubeYtDlpBridge\config.json`, paste it into the extension
   options page and run the connection test.
7. Open a supported video page and press `Ctrl+Shift+Y`.

Detailed Chinese instructions and troubleshooting are in the repository
[`README.md`](https://github.com/anyexch/video-download-companion#下载安装与使用推荐).

## Highlights

- Capture supported YouTube, Bilibili and Douyin pages from a Chrome extension.
- Persist jobs in SQLite with bounded concurrency, retries and restart recovery.
- Detect versions from the actual configured yt-dlp, JavaScript runtime, FFmpeg and DouK paths.
- Keep external dependency paths read-only unless the user explicitly chooses adoption.
- Download, verify and self-test a managed candidate before switching configuration.
- Preserve the external original and recover configuration after failed or interrupted adoption.

## Assets

- `Video-Download-Companion-Setup-0.1.15.exe`: Windows online installer.
- `video-download-companion-extension-0.6.0.zip`: unpacked Chrome extension package.
- `verify-installed.ps1`: post-install verification for a clean Windows VM.
- `SHA256SUMS.txt`: release asset hashes.
- `THIRD_PARTY_NOTICES.md`: third-party programs and license summary.

## Important notes

- The installer is not Authenticode signed. Windows SmartScreen may show an unknown-publisher warning.
- The installer downloads pinned yt-dlp 2026.08.19, Deno 2.9.7 and DouK 5.8 assets and verifies SHA-256. It obtains the current FFmpeg `latest` asset metadata and digest from the official GitHub Release API immediately before download.
- Platform login, Cookie access and DouK disclaimer acceptance remain local user actions.
- Download only content you are authorized to access and comply with the platform rules and applicable law.
